# Contextualising Earth Observation Data through Visual Interpretation

**Instructor:** Lina Eklund  
**24 September 2026 · SESAC Beginner Earth Observation Analysis Series**

This session introduced the importance of context and visual interpretation in Earth Observation analysis.

Participants explored how visual interpretation, local knowledge and landscape context can complement quantitative satellite-derived information, with attention to features such as shape, size, pattern, texture, colour, shadow, location and association.

The practical exercise used **Google Earth Pro** to explore satellite imagery, identify land-cover and land-use features, compare different geographic settings and discuss interpretation challenges.
